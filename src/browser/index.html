About this browser pilot

No sign-in, analytics, AI requests, or automatic clipboard access. Copy and paste is deliberate. Word definitions remain in the Windows app for now.

Clear removes the passage from the Station and stops playback. Browser extensions, operating-system features, and browser session restoration are outside Reed’s control. When hosted on GitHub Pages, GitHub logs visitor IP addresses for security; Reed does not receive a reading history.

Mac Safari and Chrome listening and background behavior still need real-device pilot testing. Automated browser checks do not verify audible voice quality.
